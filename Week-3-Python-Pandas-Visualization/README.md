# Week 3 - Python, Pandas & Data Visualization

## Overview

This project demonstrates the use of Python, Pandas, Matplotlib, and Seaborn for data analysis and visualization using a workout dataset.

## Objectives

- Understand Python data structures and functions
- Load and explore CSV data using Pandas
- Filter, sort, and analyze data
- Merge datasets using Pandas
- Create visualizations using Matplotlib
- Create statistical visualizations using Seaborn

## Technologies Used

## Dataset

The dataset contains workout-related information including:

- Duration
- Date
- Pulse
- Maximum Pulse
- Calories

## Key Insights

The analysis explores the relationship between workout duration, pulse, maximum pulse, and calories burned.
